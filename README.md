## About
NurseryNextDoor is a clean, mobile-first website showcasing plant products and gardening information. The site focuses on accessibility, a friendly user interface, and fast static delivery. It is implemented primarily with semantic HTML and CSS, with minimal JavaScript for interactive bits.

Live site: https://nurserynextdoor.netlify.app

---

## Features
- Responsive layout for desktop, tablet, and mobile
- Product / plant listings and informational sections
- Contact / call-to-action area for inquiries
- Clean visual design with CSS styling
- Lightweight static site for fast loading and easy deployment

## Getting started

Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: a local static server (Live Server extension for VS Code, Python http.server, or any static hosting)

Run locally
1. Clone the repo:
   git clone https://github.com/iamashwinishinde/NurseryNextDoor.git

2. Open the project folder:
   cd NurseryNextDoor

3. Open index.html in your browser directly, or run a simple static server:
   - Using Python 3:
     python3 -m http.server 8000
     Then open http://localhost:8000 in your browser.
   - Or use VS Code Live Server extension and click "Go Live".
